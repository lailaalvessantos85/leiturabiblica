# Leitura da Bíblia

Página para acompanhar a leitura da Bíblia (66 livros), organizada por divisões, com percentual lido e faltante, meta de término, histórico das últimas 8 semanas e backup do progresso.

## Como funciona

- É um único arquivo, `index.html`, sem instalação nem banco de dados.
- O progresso de cada pessoa fica salvo no próprio navegador.
- O botão "Gerar backup" cria um código para restaurar as leituras em outro aparelho.

## Publicação

Hospedado na Vercel a partir deste repositório. Qualquer alteração no `index.html` enviada ao GitHub é publicada automaticamente.
